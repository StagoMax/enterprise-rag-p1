# P3 RAG 修复实施与复测报告

## 结论

本轮完成了评测与线上组件统一、文档级候选聚合、显式实体特征、证据片段选择、普通 RAG 独立门槛、置信区间门槛和 hard-negative 复核队列。代码回归通过，但修复后系统仍未达到发布标准。

在不启用 reranker、保持 Nemotron 1024 / Milvus / dense weight 0.70 / Top3 的可比配置下，普通 RAG Recall@3 从 63.64% 提升到 69.09%，Top-1 从 60.00% 降到 58.18%。实体特征能将更多正确文档推入 Top3，但不足以稳定确定第一名，下一阶段仍需要经过评测的领域或 LLM 文档级重排器。

## 已完成修复

- 服务端和评测脚本共用组件 factory，评测不再固定为独立实现。
- 评测支持 `none`、通用 cross-encoder 和 LLM reranker，并记录脱敏配置与实际生效组件。
- 普通 RAG 与 exact search 分开报告，并分别计算 Recall@3、Top-1 和置信区间。
- 普通 RAG 的 85% Recall@3、95% Top-1 已纳入发布门槛。
- 质量指标增加 Wilson 置信区间下界判定；零容忍隔离指标继续要求零泄漏。
- 候选按文档聚合，每份文档最多向 reranker 提供三个问题相关分块。
- 产品、组件、错误码和版本特征只做有界正向加权，不做硬过滤。
- 摘录改为句子/段落级互补证据选择，支持英文轻量词干、错误码和中文二元组。
- 生成 55 条查询级 Top20 候选复核队列，候选默认标记为 `unreviewed`，不得未经人工确认直接用于训练。

## 可比复测

| 指标 | 修复前 | 修复后 | 变化 |
|---|---:|---:|---:|
| 基础检索 Recall@3 | 73.33% | 77.33% | +4.00 个百分点 |
| 基础检索 Top-1 | 70.67% | 69.33% | -1.34 个百分点 |
| 普通 RAG Recall@3 | 63.64% | 69.09% | +5.45 个百分点 |
| 普通 RAG Top-1 | 60.00% | 58.18% | -1.82 个百分点 |
| 可容纳答案命中率 | 59.00% | 60.00% | +1.00 个百分点 |
| MRR@3 | 0.8624 | 0.8677 | +0.0053 |
| nDCG@3 | 0.8620 | 0.8710 | +0.0090 |

修复后、未启用 reranker 时的普通 RAG Top20 诊断覆盖为 49/55（89.09%）。当时未进入 Top20 的题目为 `rag-002`、`rag-033`、`rag-034`、`rag-046`、`rag-056`、`rag-059`。后续验证发现，启用 reranker 会扩大原始分块池并重新进行文档聚合，因此这份无重排 Top20 诊断不能作为严格的 reranker 上限；NowCoding 已召回此前未进入该诊断池的 `rag-033`。需要记录真实重排路径中的候选，才能准确区分候选生成失败与排序失败。

## 外部验证更新

用户明确授权后，已使用 `.env` 中的 NowCoding 配置完成 55 条普通 RAG 专项评测。最终结果、逐题归因和后续修复优先级见 `p3-nowcoding-reranker-analysis.zh-CN.md`。

通用 MS MARCO cross-encoder 已有负收益记录，不能作为默认方案。领域 cross-encoder 训练必须先完成人工相关性复核，并按文档或产品簇划分训练集与冻结测试集，避免在当前失败题上训练后用同一批题报告提升。
