# P1 执行与验收报告

## 1. 结论

P1 的可运行闭环已经完成：身份与角色、四路路由、检索前 ACL、混合检索、只读 SQL、引用、拒答、审计、反馈、固定金标评测和内部工作台均可运行。

当前基线不能进入 P2。唯一阻断项是 Top-1 引用正确率 87.5%，低于 95% 门槛。该结论不通过降低门槛、修改金标或把 Top-3 命中冒充 Top-1 来规避。

## 2. 数据执行结果

| 数据 | 实际结果 | RAG 边界 |
|---|---|---|
| TechQA-RAG-Eval | WebSphere 单领域 200 篇文档 | 进入 RAG；用于内部技术知识代理 |
| BIRD-SQL Mini-Dev | `financial` 数据库，8 表、32 题 | 不进入 RAG；只读 SQL 工具访问 |
| 金标集 | 120 题且 ID 唯一 | 不进入索引；只用于回归评测 |

金标分布为 60 条 RAG、20 条精确检索、20 条工具调用、10 条越权和 10 条无证据。TechQA 使用 `security-support`、`engineering-support`、`operations-support` 三类业务分类，并分别映射到 `restricted`、`engineering`、`operations` 角色；ACL 在关键词和向量打分前执行。

BIRD 的 32 条官方 SQL 均通过 AST 白名单、只读连接并成功执行，执行成功率 100%，隔离复测 P50 为 3.018 ms，P95 为 465.317 ms。

## 3. 模型与检索决策

固定对照条件为同一 200 篇文档、120 题、权限策略、分块、BM25 和 0.5 混合权重。

| 配置 | Recall@3 | Top-1 引用 | P95 | 索引时间 | 结论 |
|---|---:|---:|---:|---:|---|
| Nemotron 1B / 1024 | 96.25% | 87.5% | 283.27 ms | 74.35 s | 默认开发基线 |
| Nemotron 1B / 2048 | 96.25% | 87.5% | 307.79 ms | 82.43 s | 无质量收益，不采用 |
| BGE-M3 / 1024 | 96.25% | 85% | 245.36 ms | 84.76 s | 更快但 Top-1 较低 |
| Nemotron 1024 + MiniLM 重排 | 96.25% | 82.5% | 442.46 ms | 125.47 s | 质量和延迟均退化 |

默认选择 `Nemotron-3-Embed-1B-BF16`、1024 维、无重排器。模型输出使用 `query:` / `passage:` 前缀，切片后重新 L2 归一化。1024 维相对 2048 维节省一半向量存储，当前金标上没有质量损失。

## 6. 进入 P2 前的动作

1. 对 Top-1 失败题进行人工归因，区分标题缺失、分块错位、近重复文档、金标歧义和重排器域不匹配。
2. 只针对已确认的失败类型试验标题/正文双通道、文档级聚合和面向技术支持语料训练的重排器。
3. 补齐 PDF、DOCX、PPTX、XLSX、HTML 和扫描 PDF 的解析测试包，验证锚点、表格分流和权限继承。
4. 使用真实部门的已分类、已授权、小规模语料复跑全部 120 类验收场景。
5. 只有 Top-1 引用和多格式准入均通过后，才启动中等规模 Graph RAG；SAG 继续保留为待正式定义的大规模阶段名称。
